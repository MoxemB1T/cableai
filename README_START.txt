CABLE AI 2.0 + free-search-mcp
==============================

Что изменено
------------
1. Qwen сначала извлекает ВСЕ отдельные позиции кабелей из письма.
2. Для КАЖДОЙ позиции автоматически выполняется поиск в локальном каталоге.
3. Для КАЖДОЙ позиции автоматически проверяются склад и товары в пути.
4. Для КАЖДОЙ позиции автоматически запускается web research через free-search-mcp.
5. Только после этого Qwen выбирает аналоги из нашего каталога.
6. Python гарантирует ровно одну строку rows на каждую извлечённую позицию.
7. Thinking отключён.
8. Финальный вызов Qwen не использует tool-calling, чтобы не зависеть от решения модели
   «вызывать web_search или нет» и чтобы уменьшить задержку.
9. Web research ограничен 3500 символами на позицию и depth=1.

Запуск
------
Окно 1:
    start_free_search_mcp.bat

Окно 2:
    start_cable_ai.bat

Или:
    start_all.bat

Порты
-----
Ollama:           http://127.0.0.1:11434
Cable AI:         http://0.0.0.0:8000
free-search-mcp:  http://127.0.0.1:8001/mcp

Каталог и наличие
-----------------
Используются те же локальные источники и catalog.db.
Если нужно пересоздать БД:
    python import_data.py --pdf "путь\к\каталогу.pdf" --xlsx "путь\к\остаткам.xlsx"

Важно
-----
Веб-поиск теперь НЕ выбирается Qwen'ом. Он выполняется автоматически для каждой
выделенной позиции письма. Это сделано специально, чтобы модель не могла пропустить
позиции или решить, что web_search «не нужен».

free-search-mcp запускается только на 127.0.0.1.

Проверка
--------
После запуска открой:
    http://localhost:8000/health
